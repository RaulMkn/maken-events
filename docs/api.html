Referencia de la API

Todos los endpoints van bajo /api. Las respuestas son JSON salvo el CSV.

Autenticación. Las rutas de admin requieren la cookie de sesión de administrador (login con contraseña + TOTP). Las de staff requieren la cookie de sesión de staff (login con contraseña). Sin la cookie válida devuelven 401.

Público

POST /api/registro

Registra un asistente. Rate limit: 10 peticiones/minuto. Controla duplicados por email.

Cuerpo:

{
  "nombre": "Ada",                 // obligatorio
  "apellidos": "Lovelace",         // opcional
  "email": "ada@example.com",      // obligatorio, único
  "disfrazado": true,              // obligatorio
  "disfraz": "bruja",              // obligatorio si disfrazado = true
  "deParteDe": "Maken",            // obligatorio (fiesta cerrada)
  "aceptaCondiciones": true        // obligatorio, debe ser true
}

Respuestas: 201 ok · 400 validación · 409 email ya registrado.

GET /api/health

Comprobación de salud. Devuelve { "ok": true }.

Administración

Prefijo /api/admin. Todas exigen sesión de admin (salvo el login).

POST /api/admin/login

Login con doble factor. Rate limit: 5 intentos/5 minutos.

{ "usuario": "admin", "password": "…", "totp": "123456" }

Devuelve 200 y establece la cookie de sesión, o 401.

POST /api/admin/logout   GET /api/admin/sesion

Cierra sesión / comprueba si la sesión sigue activa.

GET /api/admin/asistentes

Devuelve el resumen y la lista de asistentes.

{
  "resumen": { "total": 12, "pagados": 8, "pendientes": 4, "disfrazados": 9, "entrados": 3 },
  "asistentes": [ { "id": "...", "nombre": "...", "deParteDe": "...", "estadoPago": "pagado",
                    "emailEnviado": true, "haEntrado": false, "precioPagadoCentimos": 700, ... } ]
}

GET /api/admin/asistentes.csv

Descarga la lista completa en CSV (con BOM para Excel). Útil como copia y lista de puerta.

POST /api/admin/asistentes/:id/confirmar-pago

Marca el pago como confirmado, fija el precio pagado (el vigente en ese momento), genera un código de QR único y envía la entrada por email.

// respuesta si el email salió
{ "ok": true, "emailEnviado": true }
// si el email falló (el pago SÍ queda confirmado)
{ "ok": true, "emailEnviado": false, "aviso": "…revisa el correo…" }

409 si ya estaba pagado.

POST /api/admin/asistentes/:id/reenviar-email

Reenvía la entrada de un asistente ya confirmado.

DELETE /api/admin/asistentes/:id

Elimina un asistente. Si estaba pagado, su QR deja de ser válido en la puerta.

GET / PUT /api/admin/ajustes

Lee o fija el precio de entrada. El importe va en céntimos.

PUT  { "precioEntradaCentimos": 700 }   // 7,00 €

GET / POST /api/admin/gastos   DELETE /api/admin/gastos/:id

Gestión de gastos del evento (dashboard financiero). Importe en céntimos.

POST { "concepto": "Hielo y vasos", "importeCentimos": 1250 }

GET /api/admin/finanzas

Resumen económico. Los ingresos son la suma de lo realmente pagado por los confirmados.

{ "ingresosCentimos": 5600, "gastosCentimos": 1250,
  "beneficioCentimos": 4350, "precioEntradaCentimos": 700 }

Staff (puerta)

Prefijo /api/staff. Login simple, sin doble factor.

POST /api/staff/login

Login con la contraseña compartida. Rate limit: 10/5 minutos.

{ "password": "…" }

POST /api/staff/verificar

Valida el código de un QR y, si es válido, marca la entrada como usada.

{ "token": "codigo-del-qr" }

// resultados posibles:
{ "resultado": "valida", "nombre": "Ada Lovelace", "disfrazado": true, "disfraz": "bruja", "deParteDe": "Maken" }
{ "resultado": "ya_entro", "nombre": "…", "motivo": "Esta entrada ya se usó.", "entradoEn": "…" }
{ "resultado": "invalida", "motivo": "QR no válido o no reconocido." }

POST /api/staff/logout   GET /api/staff/sesion

Consulta de entrada (admin)

POST /api/entrada/verificar

Consulta una entrada por su código sin marcarla como usada. Requiere sesión admin.
